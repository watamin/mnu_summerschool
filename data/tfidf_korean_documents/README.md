# TF-IDF 실습용 한국어 문서

03장의 문서 비교 활동에서 읽는 자료입니다. 세 파일은 Microsoft의 `AI-For-Beginners` 한국어 번역 자료를 커밋 `33e781bf7bfb9b39fd27c4e4a3e592669b52cb4b`에서 내려받은 원문입니다. 신경망, 컴퓨터 비전, 책임 있는 AI처럼 주제가 다른 문서를 골라 문서별 특징어가 어떻게 달라지는지 살펴봅니다.

`sources.json`에는 각 파일의 원문 위치, 고정된 다운로드 주소, SHA-256 값이 적혀 있습니다. 노트북은 실행할 때 파일의 SHA-256을 확인하므로 원문이 빠졌거나 바뀌면 분석을 계속하지 않고 알려 줍니다. 파일을 저장소에 함께 둔 까닭은 교실 인터넷이 끊겨도 수업을 이어 가기 위해서입니다.

원문 저장소는 MIT 라이선스로 배포됩니다. 라이선스 전문은 `UPSTREAM_LICENSE.txt`에 보존했습니다. 문서 안의 이미지나 외부 링크는 온라인에서만 열릴 수 있지만, TF-IDF 실습은 이 폴더의 글만으로 실행됩니다.
