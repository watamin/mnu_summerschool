# 학생 프로젝트 워크시트

## 프로젝트 한 문장

우리는 NEIS의 우리 학교 급식 데이터와 이름 없는 취향 프로필을 비교해, 추천 이유를 설명하는 개인별 급식 AI 서비스를 만든다.

## 절대 입력하지 않는 정보

- 이름, 학번, 반, 연락처
- 체중, 질병명, 진료 내용
- 실제 개인과 연결되는 알레르기 기록
- API 키와 비밀번호

## 6인 순환 역할표

학생 번호 A~F를 정하고 매회 역할을 한 칸씩 옮긴다. 한 역할을 한 학생만 계속 코딩하지 않는다.

| 역할 | 하는 일 | 1회차 | 2회차 | 3회차 | 4회차 | 5회차 |
|---|---|---|---|---|---|---|
| 데이터 탐험가 | NEIS 필드·학교 코드·출처 확인 | A | F | E | D | C |
| 전처리 담당 | 메뉴·HTML·알레르기·영양 열 확인 | B | A | F | E | D |
| 시각화 담당 | 표·그래프·데이터 설명 | C | B | A | F | E |
| 추천 모델 담당 | TF-IDF·유사도·군집 설명 | D | C | B | A | F |
| 서비스·테스트 담당 | Gradio·시험 사례·오류 기록 | E | D | C | B | A |
| 윤리·발표 담당 | 개인정보·안전·모델 카드·발표 | F | E | D | C | B |

| 피하고 싶은 재료·메뉴 | 최대 5개 | 오이 | 개인 식별 안 됨 |

| 매운맛 선호 | 1~5 | 2 | 개인 식별 안 됨 |
| 알레르기 주의 번호 | 1~19, 가상 시험만 | 비움 | 실제 개인 정보 입력 금지 |

## 4. 추천 점수 설명 카드

공개 점수식: `0~100으로 제한(20 + 70×텍스트유사도 + 8×좋아함 일치 수 + 5×선호유형 일치 수 - 18×기피 일치 수 - 3×매운맛 차이)`

- 20점 기준점: 감점 결과가 0점 하한에서 바로 사라지지 않게 하는 출발점

- 텍스트 유사도: 취향 문장과 메뉴 문장의 글자 패턴이 얼마나 가까운가
- 좋아하는 키워드: 일치할 때 보너스
- 선호 메뉴 유형: 일치할 때 보너스
- 피하고 싶은 키워드: 일치할 때 감점
- 매운맛 차이: 차이가 클수록 감점
- 알레르기 주의 번호: 일치하면 추천 후보에서 제외
