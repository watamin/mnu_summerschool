# 학생 프로젝트 활동지

## 우리가 만들 것

NEIS에서 가져온 우리 학교 급식과 가상 취향을 비교해 추천 메뉴 세 개와 그 이유를 보여 주는 Jupyter 추천기를 만듭니다.

이 활동지는 코드를 얼마나 많이 썼는지 적는 곳이 아닙니다. 내가 바꾼 값, 화면에서 달라진 것, 그렇게 생각한 까닭을 남기는 곳입니다.

## 입력하지 않을 정보

- 이름, 학번, 반, 연락처
- 체중, 질병명, 진료 내용
- 실제 개인과 연결되는 알레르기 기록
- 비밀번호와 API 키
