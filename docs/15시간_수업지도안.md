# 우리 학교 급식 AI 프로젝트 수업 지도안

## 수업 개요

- 대상: 코딩 기초를 조금 배운 중학교 2학년 6명
- 환경: 학생 1인당 PC 1대, 로컬 Jupyter Notebook, 한국어 수업
- 제작 시간: 3시간씩 5회, 모두 15시간
- 발표 시간: 6회차 3시간
- 기본 데이터: 남악고등학교 NEIS 급식식단정보
- 결과물: 가상 취향을 입력하면 메뉴 세 개와 추천 이유를 보여 주는 Jupyter 화면

학생마다 같은 노트북을 실행하지만 입력값과 관찰 기록은 직접 작성합니다. 수업에서는 완성된 코드를 받아 적기보다 값 하나를 바꾸고, 결과가 달라진 까닭을 설명하는 데 시간을 씁니다.

## 수업 전 준비

1. 프로젝트 폴더를 학생 PC의 짧은 경로에 복사합니다.
2. `jupyter_course/00_설치_준비.md`를 인쇄하거나 별도 화면에 띄웁니다.
3. Python 3.11 이상, 인터넷 연결, PowerShell 실행을 확인합니다.
4. 교사용 PC에서 00장과 06장을 새 커널로 실행합니다.
5. NEIS 연결이 되지 않을 때 예비 데이터 5행으로 전환되는지 확인합니다.
6. 실제 학생의 알레르기나 질병 정보를 입력하지 않는다는 안내를 준비합니다.

## 3회차 — 글자를 숫자로 바꾸어 비교하기

사용 파일: `03_TFIDF_글자를_숫자로.ipynb`, `04_유사도와_식단군집.ipynb`

| 시간 | 함께 할 일 | 학생 기록 |
|---:|---|---|
| 0~15분 | 두 칸·세 칸 창으로 n-gram 만들기 | `·파스타·`의 2-gram과 3-gram |
| 15~35분 | 작은 문서 계산표 완성하기 | A·B·C의 횟수·TF·DF·IDF·TF-IDF 여섯 행 |
| 35~50분 | A 문서의 `피자` 계산 추적하기 | `1÷15×1.6931=0.1129` 설명 |
| 50~60분 | 내려받은 한국어 문서 세 편 확인하기 | 출처와 297·570·391개 분석 단어 수 |
| 60~78분 | 문서별 상위 계산표 읽기 | 1위 단어의 횟수부터 TF-IDF까지 기록 |
| 78~90분 | TF-IDF를 실제 메뉴 비교에 연결하기 | 날짜별 순위·유사도·공통 조각 수 |
| 90~100분 | 휴식 |  |
| 100~125분 | 코사인 유사도를 방향으로 이해하기 | 값이 클 때 뜻하는 것 |
| 125~150분 | K-Means로 식단 묶기 | 각 묶음에 들어간 날짜 |
| 150~170분 | 군집 수를 2와 3으로 바꾸기 | 묶음이 달라진 부분 |
| 170~180분 | 두 방법 비교 | 유사도와 군집의 차이 |

TF는 한 문서 안의 비율, DF는 해당 조각을 포함한 문서 수, IDF는 드문 정도라는 말을 구분해서 사용합니다. 실제 문서 활동에서는 `뉴런` 0.0342, `이미지` 0.0407, `책임` 0.0260이 나온 과정을 등장 횟수·전체 단어 수·TF·DF·IDF 순서로 읽게 합니다. `이미지`는 DF가 2라 IDF가 작지만 TF가 커서 높은 점수를 받는다는 점까지 말해야 계산을 이해한 것입니다. 단순한 한글 단어 분리는 조사를 완전히 떼지 못한다는 한계와, 문서 출처·라이선스·SHA-256을 함께 기록한 까닭도 짚습니다. 군집 이름은 해당 자료 안에서 수치가 상대적으로 비슷하다는 뜻이며 건강하거나 안전하다는 판정으로 사용하지 않습니다.

## 생성형 AI를 사용할 때

학생이 생성형 AI에 질문할 수는 있지만, 받은 코드를 그대로 최종 파일에 붙이지 않습니다.

1. 질문에는 원하는 입력과 출력을 함께 적습니다.
2. 새 코드는 복사본이나 새 셀에서 먼저 실행합니다.
3. NEIS 필드명은 원본 JSON과 비교합니다.
4. 한 줄씩 설명할 수 없는 코드는 최종 파일에서 빼 둡니다.
5. 학생 개인정보, API 키, 학교 내부 문서는 입력하지 않습니다.
