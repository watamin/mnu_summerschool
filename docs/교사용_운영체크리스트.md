## 머신러닝 기초와 벡터 표현

- [ ] 평점 표에서 특성 `X`와 정답 `y`를 구분했다.
- [ ] 메뉴 이름을 원-핫 벡터로 바꾸는 까닭을 설명했다.
- [ ] 음식별 평균이 학습된 값이 되는 과정을 표에서 확인했다.
- [ ] 김치 벡터와 학습된 값의 내적으로 예상 평점 5.0을 계산했다.
- [ ] 실제 평점 4.0과 예상 평점 5.0의 절대오차가 1.0인지 확인했다.
- [ ] 원-핫만으로 새 메뉴와 의미상 유사성을 다루기 어려운 까닭을 설명했다.
- [ ] `·파스타·`를 2-gram과 3-gram으로 직접 나누었다.
- [ ] TF의 분자와 분모를 구분했다.
- [ ] DF가 반복 횟수가 아니라 해당 조각을 포함한 문서 수임을 설명했다.
- [ ] `파스`와 `피자`의 DF·IDF를 비교했다.
- [ ] TF와 IDF를 곱해 한 조각의 TF-IDF를 계산했다.
- [ ] 한국어 원문 세 파일의 출처와 MIT 라이선스를 확인했다.
- [ ] 문서별 분석 단어 수가 신경망 297개, 컴퓨터 비전 570개, 책임 있는 AI 391개인지 확인했다.
- [ ] 세 문서의 1위가 `뉴런` 0.0342, `이미지` 0.0407, `책임` 0.0260인지 확인했다.
- [ ] 1위 단어의 등장 횟수·TF·DF·IDF·TF-IDF를 한 줄의 계산식으로 설명했다.
- [ ] 같은 단어가 다른 문서에서 받은 점수를 비교했다.
- [ ] 불용어를 빼는 까닭과 단순 단어 분리의 한계를 설명했다.
- [ ] 세 문서의 SHA-256 확인 결과가 모두 `True`인지 확인했다.
- [ ] 취향 단어를 바꾸고 날짜별 유사도 순위와 공통 글자 조각 수 변화를 기록했다.
- [ ] 코사인 유사도가 방향을 비교한다는 점을 설명했다.
- [ ] K-Means 군집 수 2와 3을 비교했다.
- [ ] 식단 묶음이 건강 등급이 아니라고 설명했다.

## 문제가 생겼을 때

| 문제 | 확인 순서 | 수업을 계속하는 방법 |
|---|---|---|
| 학교 검색 오류 | 인터넷 → 학교명 → 잠시 뒤 재실행 | 예비 자료로 API 구조 설명 |
| 급식 GET 요청 오류 | URL → 학교 코드 → 날짜 → 상태 코드 | 오류를 기록하고 예비 자료로 JSON 경로 연습 |
| JSON 경로 오류 | 현재 자료형 → 키 목록 → 배열 길이 | 중간 변수별로 `type()`과 `keys()` 출력 |
| 선택 기간에 급식이 없음 | 주말·방학 → 날짜 형식 | 예비 데이터 날짜로 바꾸기 |
| Pandas 열 오류 | 앞쪽 전처리 셀 실행 여부 | 커널을 다시 시작하고 전체 실행 |
| 추천 결과가 비어 있음 | 가상 알레르기 번호 | 제외된 수를 설명하고 번호 바꾸기 |
| 그래프가 보이지 않음 | 02장 위쪽 코드 셀 | 표를 먼저 읽고 전체 실행 |
| 입력 위젯이 보이지 않음 | `pip show ipywidgets` | 패키지 재설치 후 커널 다시 시작 |
| 한글이 그래프에서 깨짐 | 글꼴 경고 | 같은 내용을 표로도 확인 |
| 코드가 많이 지워짐 | 원본 노트북 | 같은 셀만 실습 사본에 복사 |
