# 교사용 운영 체크리스트

## 수업 전날 30분 점검

- [ ] 학생용 노트북을 Colab에 업로드하고 `런타임 → 모두 실행`한다.
- [ ] 첫 데이터 출처가 `실시간 NEIS 데이터` 또는 `내장 NEIS 예비 데이터`로 표시되는지 확인한다.
- [ ] 추천 결과가 1개 이상이며 점수가 0~100 사이인지 확인한다.
- [ ] Gradio 화면이 열리고 버튼을 두 번 눌러도 오류가 없는지 확인한다.
- [ ] 가상 알레르기 번호 5를 선택했을 때 해당 번호 메뉴가 제외되는지 확인한다.
- [ ] Colab 마지막 셀에 임시 공개 Gradio 링크가 생성되는지 확인한다.
- [ ] 학생 6명의 Google 계정과 PC·인터넷 접속을 확인한다.
- [ ] 학생용 원본은 보기 전용으로 보관하고 회차별 사본 폴더를 만든다.
- [ ] 발표용 복사본과 예비 데이터 화면 캡처를 별도로 저장한다.

## 학교와 API 확인값

- 기본 학교: 남악고등학교
- NEIS 교육청 코드: `Q10`
- NEIS 학교 코드: `7140272`
- 학교 검색 API: `https://open.neis.go.kr/hub/schoolInfo`
- 급식 API: `https://open.neis.go.kr/hub/mealServiceDietInfo`
- 기본 조회 범위: `20260101`~`20261231`
- 현재 예비 데이터: NEIS가 2026년 7월 26일 반환한 남악고 중식 5건
- 예비 데이터 실제 날짜: `20260624`~`20260630`(요청 날짜와 겹치는 행만 사용)

다른 학교를 사용할 때는 정확한 공식 학교명을 먼저 `schoolInfo`로 검색한다. 확인되지 않은 `삼향고등학교` 이름은 수업 자료에 고정하지 않는다.

## API 키 운영

현재 공개 엔드포인트는 키 없이도 조회되는 구간이 있지만 정책은 바뀔 수 있다. 인증키가 필요해지면 다음 원칙을 적용한다.

- 교사 계정으로 발급하고 학생 공유 노트북에 평문으로 적지 않는다.
- Colab Secrets의 `NEIS_API_KEY`에 저장한다.
- 화면 캡처와 발표 자료에 키가 노출되지 않는지 확인한다.
- 키 발급이 늦어도 예비 데이터로 전체 수업을 진행할 수 있게 한다.

## 장애 대응표

| 증상 | 확인 순서 | 수업 중 해결 |
|---|---|---|
| 학교 검색 서버 오류 | 인터넷 → 학교명 → 잠시 후 재실행 | 자동 예비 데이터 사용, API 원리는 캡처로 설명 |
| 선택 기간에 데이터 없음 | 방학·주말 여부 → 날짜 형식 | 예비 데이터 안내 기간(`20260624`~`20260630`) 또는 다른 실시간 기간 사용 |
| Pandas 열 오류 | 이전 전처리 셀 실행 여부 | `런타임 다시 시작` 후 위에서부터 실행 |
| 추천 결과가 비어 있음 | 알레르기 선택 번호 확인 | 제외된 메뉴 수를 설명하고 번호를 바꿔 재시험 |
| Gradio가 열리지 않음 | 설치 셀 → 런타임 연결 | 표 형태 추천 결과로 발표하고 UI는 캡처 사용 |
| 한글 글꼴이 그래프에서 깨짐 | Colab 기본 글꼴 상태 | 제목을 영어로 바꾸지 말고 표 출력을 함께 사용 |
| 학생이 코드를 크게 삭제 | 실행 기록·공유본 확인 | 교사 원본에서 해당 셀만 복사 |
| 생성형 AI 코드가 길고 오류 발생 | 입력·출력 설명 가능 여부 | 팀 완성본에는 넣지 않고 기본 제공 함수 복원 |

## 개인정보·알레르기 점검

- [ ] Google Form이나 공유 표에 이름과 알레르기를 연결해 저장하지 않는다.
- [ ] 시연용 프로필은 가상의 취향으로 만든다.
- [ ] 실제 학생의 알레르기를 코드 셀·임시 Gradio 링크·발표 화면에 입력하거나 공개하지 않는다.
- [ ] 결과 화면의 영양사 재확인 문구를 삭제하지 않는다.
- [ ] `안전한 메뉴`, `건강한 메뉴`, `먹어도 된다`라고 단정하지 않는다.

## 내일 검토 순서 20분

1. 학생용 노트북의 제목·학습목표·입력값을 3분 동안 확인한다.
2. `모두 실행` 후 결과 표와 Gradio 화면을 5분 동안 시험한다.
3. 지도안의 1~5회차 산출물과 실제 학교 일정이 맞는지 5분 동안 확인한다.
4. 학생 역할 순환표와 평가 루브릭을 4분 동안 확인한다.
5. 학교명·날짜·발표 시간에서 바꿀 항목을 3분 동안 표시한다.
