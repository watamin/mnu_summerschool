# 교사용 NEIS 실제 급식 데이터 갱신

학생에게 인증키를 나누어 주지 않습니다. 교사가 수업 전에 한 번 수집한 뒤, 공개 급식 데이터가 담긴 `data/namak_meals_live.json`만 학생용 프로젝트에 포함합니다.

## 1. 인증키 파일 준비

NEIS 교육정보 개방 포털에서 발급한 인증키 한 줄을 `neis.txt`에 저장합니다. 이 파일은 프로젝트 폴더 바깥의 교사 전용 위치에 둡니다.

```text
영문과 숫자로 된 인증키 한 줄만 저장
```

인증키 전체를 수업 화면, 노트북, 메신저, GitHub에 붙여 넣지 않습니다. 프로젝트의 `.gitignore`는 프로젝트 안에 실수로 만든 `neis.txt`와 `.env`도 Git에서 제외합니다.

## 2. 실제 급식 수집

프로젝트 최상위 폴더의 PowerShell에서 실행합니다. 날짜는 `YYYYMMDD` 형식입니다.

```powershell
.\.venv\Scripts\python.exe scripts\collect_live_meals.py `
  --key-file "C:\교사용\neis.txt" `
  --school "남악고등학교" `
  --start 20260301 `
  --end 20260729 `
  --output data\namak_meals_live.json
```

스크립트는 키를 현재 Python 프로세스에서만 `NEIS_API_KEY`로 사용합니다. 수집이 끝나면 이전 환경 변수 상태로 되돌리고, 화면에는 키를 출력하지 않습니다.

## 3. 수집 파일 확인

성공하면 학교명, 요청 기간, 수집한 중식 일수만 표시됩니다. JSON에는 다음 내용만 저장됩니다.

- 남악고등학교 교육청 코드와 학교 코드
- 요청 시작일·종료일과 UTC 수집 시각
- 수집된 공개 중식 행 수
- NEIS가 제공한 날짜·메뉴·영양·알레르기 표시 정보

인증키와 학생 개인정보는 저장하지 않습니다.

## 4. 웹 추천기 실행

```powershell
.\.venv\Scripts\python.exe web_app.py
```

웹 추천기는 `namak_meals_live.json`이 정상이라면 실제 수집본을 먼저 사용합니다. 화면 상단에 학교명, 실제 사용 일수, 첫·마지막 급식 날짜, 수집일이 표시됩니다.

실제 수집본이 없거나 JSON이 손상되면 수업이 중단되지 않도록 5일 예비 데이터로 자동 전환하고, 화면에 `실제 수집본 오류로 예비 자료 사용`이라고 표시합니다.

## 5. 수업 전 확인

1. 웹 화면의 데이터 출처가 `NEIS 실제 수집 데이터`인지 확인합니다.
2. 가상 취향으로 추천 버튼을 누르고 결과가 3행인지 봅니다.
3. 이름·학번·실제 알레르기 정보가 입력되지 않았는지 확인합니다.
4. 수집 파일만 학생 PC에 배포하고 `neis.txt`는 배포하지 않습니다.

인증키가 채팅, 메일 본문, 공개 저장소에 노출되었다면 해당 키를 폐기하고 새로 발급받습니다.
