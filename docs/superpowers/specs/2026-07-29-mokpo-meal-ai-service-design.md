# 목포권 학생 급식 AI 웹 서비스 설계

## 1. 목표와 범위

목포시 소재 중학교·고등학교의 NEIS 공개 급식 데이터를 이용해 학생이 취향을 탐색하고 학교별 식단 특징을 비교하는 로컬 Gradio 웹 서비스를 만든다. 중학교 2학년 학생이 계산 근거를 설명할 수 있어야 하므로 TF-IDF 결과와 임베딩 결과를 함께 보여 주며, 모델이 만든 점수는 실제 만족도 조사 결과가 아니라 `수업용 예측 점수`라고 표시한다.

서비스 이름은 `목포 급식 AI 탐험실`로 한다. 기존 남악고 추천기는 그대로 보존하고, 새 서비스는 `mokpo_service.py`로 실행한다.

## 2. 채택한 구현 방식

### 채택: 기존 Python·Gradio 확장

현재 저장소의 NEIS 수집, Pandas 정리, TF-IDF 추천, Gradio 화면을 재사용한다. 별도 JavaScript 프런트엔드나 데이터베이스를 추가하지 않는다. 학생은 Python 함수와 표를 연결해 전체 흐름을 이해할 수 있다.

### 제외한 방식

- Streamlit 전면 재작성: 기존 UI와 테스트를 다시 만드는 비용이 크다.
- FastAPI와 별도 프런트엔드: 배포 확장성은 높지만 15시간 수업 범위를 넘는다.
- 생성형 LLM 식단 평가: 급식 데이터만으로 근거를 검증하기 어렵고 API 비용·안전 문제가 생긴다.

## 3. 개인정보 원칙

- 실제 이름, 학번, 반, 연락처, 질병명은 받거나 저장하지 않는다.
- 화면에서 사용할 별명은 선택 사항이며 현재 요청의 결과 문구에만 쓰고 파일에 기록하지 않는다.
- 나이 대신 `중1·중2·중3·고1·고2·고3` 학년 구간을 사용한다.
- 알레르기 번호는 수업용 가상 값만 입력하게 하고 실제 건강 판단에 사용하지 않는다.
- 밥친구 기능은 `학생A`처럼 익명 표시명과 취향 문장만 한 번에 입력하며 서버·파일에 저장하지 않는다.

## 4. 데이터 파이프라인

### 4.1 학교 목록

NEIS `schoolInfo`에서 전남교육청 코드 `Q10`의 학교를 조회한 뒤 도로명 주소에 `목포시`가 들어 있고 학교 종류가 `중학교` 또는 `고등학교`인 행만 남긴다. 현재 조회 결과는 31개교다.

공개 저장 파일 `data/mokpo_schools.json`에는 학교명, 학교 종류, 교육청 코드, 학교 코드, 도로명 주소만 넣는다.

### 4.2 급식 데이터

31개교에 대해 2026-06-01부터 2026-07-29까지 NEIS 중식 데이터를 수집한다. `data/mokpo_meals_live.json`에는 학교 식별 정보와 날짜·메뉴·열량·영양·알레르기 등 공개 급식 필드만 넣는다. 인증키와 요청 URL은 저장하지 않는다.

수집기는 다음을 검증한다.

- 교육청 코드가 `Q10`인지 확인
- 학교 코드가 수집한 학교 목록에 있는지 확인
- 식사 종류가 `중식`인지 확인
- 날짜가 8자리 실제 날짜인지 확인
- 학교별 행 수와 전체 행 수가 메타데이터와 일치하는지 확인
- 실패 시 인증키나 전체 요청 URL이 출력되지 않도록 짧은 안내만 표시

## 5. AI와 분석 기능

### 5.1 개인 Best·Worst와 만족도 예측

입력은 좋아하는 음식, 피하고 싶은 음식, 선호 유형, 매운맛 단계다. 메뉴 문장과 취향 문장의 코사인 유사도를 0~1로 계산하고 다음 공개 규칙으로 0~100점 만족도를 만든다.

- 텍스트 유사도 70점
- 선호 유형 일치 최대 15점
- 매운맛 차이 최대 10점 감점
- 피하고 싶은 키워드 한 개당 20점 감점
- 점수는 0~100으로 제한

가장 높은 메뉴 5개와 가장 낮은 메뉴 5개를 함께 보여 준다. 실제 설문 정답이 없는 상태이므로 이 값은 예측 모델의 결과이지 학생의 실제 만족도가 아니다.

### 5.2 TF-IDF와 임베딩

기본 모드는 기존 문자 n-gram TF-IDF다. 선택 모드에서는 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`를 지연 로딩한다. 모델은 50개 언어를 지원하고 384차원 밀집 벡터를 만들며, 메뉴와 취향 벡터를 정규화한 뒤 내적으로 코사인 유사도를 구한다.

PyTorch가 CUDA를 사용할 수 있으면 GPU를 선택하고 그렇지 않으면 CPU를 사용한다. 모델 패키지나 가중치가 없으면 서비스가 멈추지 않고 TF-IDF로 전환하며 화면에 전환 이유를 표시한다. 자동 테스트에서는 실제 모델을 다운로드하지 않고 고정된 가짜 임베더로 계산 경계를 검증한다.

### 5.3 학교 통계와 시그니처 메뉴

- 학교별 급식 일수, 메뉴 항목 수, 평균 열량
- 학교별 자주 등장한 메뉴와 적게 등장한 메뉴
- 전체 학교에는 흔하지 않지만 특정 학교에서 상대적으로 자주 등장한 단어를 TF-IDF로 계산한 시그니처 키워드
- 학생 취향과 각 학교 식단의 평균 상위 유사도를 비교한 `입맛 맞춤형 학교 추천`

학교 추천은 교육의 질이나 진학 적합도를 평가하지 않으며 급식 취향만 비교한다고 명시한다.

### 5.4 Food MBTI와 밥친구

Food MBTI는 네 가지 설명 축을 사용한다.

- `R/E`: 밥·국 중심 / 면·간편식 중심
- `M/S`: 순한 맛 / 매운 맛
- `F/L`: 익숙한 메뉴 / 새로운 메뉴
- `D/H`: 디저트 선호 / 든든한 식사 선호

질문 응답과 메뉴 키워드로 네 글자 유형을 결정하고 근거를 출력한다. 이는 성격검사가 아니라 수업용 식성 분류다.

밥친구는 최대 6명의 익명 취향 문장을 벡터화한 뒤 모든 학생 쌍의 코사인 유사도를 계산하고 가장 가까운 짝을 추천한다. 동점은 입력 순서로 결정한다.

### 5.5 식단 실험실과 메뉴 조합

NEIS에는 식재료 원가와 잔반 실측값이 없다. 따라서 이 기능은 다음 대체지표를 사용하는 `수업용 가정 시뮬레이션`으로 표시한다.

- 가성비 대체지표: 메뉴 항목 수 대비 취향 점수
- 잔반 위험 대체지표: `100 - 익명 집단 평균 만족도 예측`
- 영양 균형 대체지표: 선택 학교 평균 열량에서 벗어난 정도

가성비는 높고 잔반 위험은 낮은 비지배 메뉴를 Pareto 후보로 표시한다. 꿀조합·꽝조합은 같은 날 함께 나온 메뉴 쌍의 빈도와 학생 취향 유사도를 이용한 탐색용 추정치이며 실제 섭취량이나 선호도 조사 결과가 아님을 표시한다.

## 6. 화면 구성

### 공통 상단

- 데이터 범위, 학교 수, 급식 일수
- TF-IDF와 임베딩의 차이
- 개인정보·알레르기·예측 한계 안내

### 탭 1: 나의 급식 추천

학교, 별명, 학년 구간, 취향, 분석 방식을 선택한다. Best·Worst 표, 만족도 막대그래프, 계산 근거를 출력한다.

### 탭 2: 학교 급식 지도

학교 종류와 학교를 선택해 빈도 통계와 시그니처 키워드를 보고, 취향 문장을 입력해 급식 취향 기준 고등학교 추천을 확인한다.

### 탭 3: Food MBTI·밥친구

네 축 질문으로 Food MBTI를 만들고, 익명 취향 목록으로 가장 가까운 밥친구 쌍과 유사도 행렬을 본다.

### 탭 4: AI 식단 실험실

학교와 익명 집단 취향을 선택해 Pareto 후보와 메뉴 조합 추정치를 본다. 실제 원가·잔반 데이터가 아니라는 경고를 결과 바로 위에 둔다.

## 7. 오류 처리

- 다중 학교 JSON이 없거나 손상되면 시작 화면에서 교사용 수집 명령을 안내한다.
- 일부 학교에 급식이 없으면 해당 학교만 제외하고 제외 학교 수를 표시한다.
- 임베딩을 사용할 수 없으면 TF-IDF로 전환한다.
- 입력이 비어 있거나 형식이 잘못되면 학생이 고칠 항목을 한국어로 알려 준다.
- UI 콜백은 인증키 파일을 읽지 않으며 네트워크 요청도 하지 않는다.

## 8. 검증 기준

- 저장소에 인증키가 포함되지 않는다.
- 목포시 중·고교 목록이 31개이며 중학교와 고등학교가 모두 포함된다.
- 공개 급식 스냅샷의 모든 행이 허용 학교·중식·유효 날짜다.
- TF-IDF와 가짜 임베딩 모드에서 코사인 유사도 결과가 재현된다.
- Best와 Worst가 겹치지 않고 점수는 0~100이다.
- 학교 시그니처, 밥친구, Food MBTI, Pareto 후보가 고정 입력에서 결정적으로 계산된다.
- Gradio 앱이 네 탭과 개인정보·모델 한계 안내를 포함한다.
- GPU 환경에서는 실제 임베딩 모델이 CUDA 장치에서 한 번 이상 문장을 벡터화한다.
- 기존 Jupyter 교과서와 남악고 추천기 테스트가 계속 통과한다.
