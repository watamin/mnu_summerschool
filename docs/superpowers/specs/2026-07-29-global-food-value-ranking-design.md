# 전체 음식 데이터 가치 랭킹 설계

## 목표

학교 선택과 관계없이 목포시 전체 급식 자료에서 중요한 음식부터 한 번에 볼 수 있는 전역 랭킹을 만든다. 같은 음식은 여러 학교에 등장해도 한 행으로 합친다.

## 계산 정의

학교 하나를 문서 하나로 본다. 음식 `f`에 대해 다음 값을 계산한다.

```text
전체 TF(f) = 전체 학교에서 f가 나온 횟수 / 전체 음식 등장 횟수
IDF(f) = ln((1 + 전체 학교 수) / (1 + f가 나온 학교 수)) + 1
전체 데이터 가치 점수(f) = 전체 TF(f) × IDF(f)
```

점수 내림차순, 전체 등장 횟수 내림차순, 음식 이름 오름차순으로 순위를 정한다. 이 점수는 음식의 영양·맛·가격이 아니라 수집 자료 전체에서 자주 보이면서 학교 문서들을 구별하는 정보량을 뜻한다.

## 결과 표

한 음식당 한 행을 만들며 다음 열을 표시한다.

- 전체 순위
- 음식
- 전체 등장 횟수
- 전체 음식 수
- 전체 TF
- 등장 학교 수
- 전체 학교 수
- IDF
- 전체 데이터 가치 점수
- 가장 많이 나온 학교
- 해당 학교 횟수

공동 최다 학교가 있으면 학교 이름 오름차순의 첫 학교를 표시한다. 상위 1위에는 실제 숫자를 대입한 TF, IDF, 곱셈 과정을 함께 보여 준다.

## 검증

- 손으로 계산 가능한 세 학교 자료로 전체 TF, IDF, 가치 점수를 검증한다.
- 같은 음식이 한 행으로 합쳐지고 순위가 결정적인지 검증한다.
- 전역 1위 설명에 실제 분자·분모·학교 수가 들어가는지 검증한다.
- Gradio 설정에 전역 랭킹 제목과 미리 계산된 표가 포함되는지 검증한다.
