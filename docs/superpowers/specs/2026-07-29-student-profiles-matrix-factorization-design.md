# 학생 프로필 저장·행렬분해 추천 설계

## 목표

교사 PC 한 대에서 급식 AI 서비스를 실행하고 같은 교실 네트워크의 학생 6명이 웹 브라우저로 접속한다. 학생은 로그인 화면에 자기 이름과 교사가 준비한 공통 비밀번호를 입력한 뒤, 배정된 음식 30개를 1~5점으로 평가한다. 응답은 SQLite에 즉시 보존되며, 모인 실제 학생×음식 평점 행렬의 빈칸은 저차원 행렬분해로 예측한다.

## 접속과 인증

- 기본 실행은 종전처럼 `127.0.0.1`에만 연다.
- `--lan` 옵션을 준 경우에만 `0.0.0.0`으로 열고 `share=False`를 유지한다.
- Gradio의 `auth(username, password) -> bool` 방식으로 로그인 화면을 제공한다.
- 로그인 사용자 이름은 학생 프로필 이름으로 사용한다. 이름은 앞뒤 공백을 정리한 1~20자의 한글·영문·숫자·공백·밑줄·붙임표만 허용한다.
- 공통 비밀번호는 저장소 밖 `../mokpo_password.txt`에서 읽는다. 코드·문서·테스트·로그에 실제 값을 넣지 않는다.
- 한 개의 공통 비밀번호를 쓰므로 다른 학생 이름을 입력하는 행위를 기술적으로 막지는 못한다. 교실에서 좌석별로 이름을 확인하고, 민감한 개인정보는 받지 않는 소규모 수업용 장치로 사용한다.

## 음식 풀과 30개 배정

- `data/mokpo_meals_live.json`에서 계산한 학교 무관 TF-IDF 데이터 가치 상위 음식 45개를 고정된 음식 풀로 저장한다.
- 모든 학생에게 공통 음식 15개를 준다.
- 나머지 30개 중 학생마다 15개를 순환 배정한다. 학생 순번 `i`의 시작점은 `(i * 5) % 30`이다.
- 학생 6명이 참여하면 순환 음식마다 세 명이 평가하게 되어 학생 사이 겹침이 생긴다.
- 배정 결과를 DB에 저장하므로 새로 고침이나 서버 재시작 뒤에도 질문 음식과 순서가 바뀌지 않는다.
- 각 학생에게 보이지 않은 나머지 15개는 실제 빈칸이며 행렬분해 예측 대상이 된다.

## 영구 저장

SQLite 파일은 기본적으로 `runtime_data/student_profiles.sqlite3`에 만들고 저장소에는 포함하지 않는다.

- `foods`: 음식명, 전체 순서, 공통 음식 여부
- `profiles`: 학생 이름, 순환 배정 순번, 만든 시각, 수정 시각
- `assignments`: 학생에게 배정된 음식과 질문 순서
- `ratings`: 학생·음식별 1~5점과 저장 시각

외래키, WAL 모드, busy timeout을 켜고 모든 SQL 값은 매개변수로 전달한다. 저장 버튼은 답한 문항만 upsert하므로 중간 저장과 이어 하기가 가능하다. 동일 이름으로 다시 로그인하면 기존 30개 평가표와 저장된 점수를 복원한다.

## 행렬분해

관측된 평점만 사용해 다음 모델을 학습한다.

```text
예측평점(u, i) = 전체평균 + 학생편향(u) + 음식편향(i) + P[u] · Q[i]
```

- NumPy 기반 확률적 경사하강법을 사용한다.
- 잠재 차원은 기본 3, 난수 seed는 고정한다.
- 예측값은 1~5 범위로 제한한다.
- 실제 빈칸을 채울 때는 모든 관측 평점으로 다시 학습한다.
- 성능 확인용으로 관측 평점의 일부를 결정적으로 가리고, 가린 실제값에 대한 MAE와 RMSE를 계산한다.
- 전체평균만 예측하는 기준선의 MAE와 나란히 표시해 행렬분해가 실제로 나아졌는지 학생이 판단하게 한다.
- 관측값이 없는 진짜 빈칸에는 정답이 없으므로 이를 정확도 평가에 사용하지 않는다.

## 화면

첫 번째 탭은 `내 프로필·30개 평가`이다.

- 현재 로그인 이름과 저장 진행률을 표시한다.
- 30개 음식과 1~5점 입력 표를 불러온다.
- 중간 저장 후 다시 불러올 수 있다.

두 번째 탭은 `학생 행렬분해 실험`이다.

- 학생별 저장 현황을 보여 준다.
- 관측 행렬과 완성 행렬을 구분해 보여 준다.
- MAE·RMSE·기준선 MAE와 계산 의미를 설명한다.
- 학생별 미평가 음식 예상 Best 5와 Worst 5를 보여 준다.
- 실제값과 예측값을 구분한 평점 열지도와 학생 잠재벡터 2차원 지도를 보여 준다.
- 전체 평점은 익명화하지 않고 교사 PC 안에서 학생 이름으로 확인하며 CSV로 내려받을 수 있다.

기존 학교 분석, 개인 역행렬 추천, MNU 검증, 피드백, NIM 기능은 그대로 보존한다.

## 오류와 운영

- 비밀번호 파일이 없거나 비어 있으면 LAN 실행을 중단하고 한글 준비 방법을 출력한다.
- 음식 풀이 45개보다 작으면 앱 생성 시 명확히 실패한다.
- 2명 미만이거나 검증용 가림 데이터를 만들 수 없으면 수치 대신 더 필요한 응답 수를 안내한다.
- DB와 내보낸 CSV는 Git에서 제외한다.
- 교사는 수업 전에 서버를 열고 Windows 방화벽에서 사설 네트워크 접근을 허용한 뒤 학생에게 `http://교사PC_IP:7860`만 알려 준다.

## 검증 기준

- 프로필 생성, 동일 이름 복원, 결정적 30개 배정, 범위 밖 평점 거절, 부분 저장, 동시 쓰기 테스트가 통과한다.
- 합성 저차원 데이터에서 행렬분해가 유한한 1~5 예측을 만들고 기준선보다 낮은 오차를 보인다.
- 실제 저장소 데이터로 6명×45개 모의 입력을 저장하고 90개 빈칸을 예측한다.
- 로그인 실패·성공, LAN 옵션, 비밀번호 누출 방지, CSV 내보내기와 실제 HTTP 응답을 확인한다.
- 전체 기존 테스트가 계속 통과한다.
