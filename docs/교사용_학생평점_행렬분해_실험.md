# 학생 평점 저장과 점심 예측 운영 안내

이 문서는 학생이 음식 30개를 평가하고, 저장된 평점으로 점심 만족도를 예상한 뒤 실제 점수와 비교하는 현재 서비스 흐름을 설명한다. 파일 이름은 기존 안내 링크를 유지하기 위해 남겨 두었다. 학생 행렬분해 실험과 로그인 절차는 현재 서비스에 포함하지 않는다.

## 1. 수업 전에 준비할 것

프로젝트 폴더에서 PowerShell을 열고 가상환경을 준비한다.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements-jupyter.txt
.\.venv\Scripts\python.exe -m pip check
```

## 2. 학생 접속용으로 실행하기

```powershell
.\.venv\Scripts\python.exe mokpo_service.py --lan
```

교사 PC에서 `ipconfig`를 실행해 학교 네트워크의 IPv4 주소를 확인한다. 예를 들어 주소가 `192.168.0.25`라면 학생에게는 다음 주소를 안내한다.

```text
http://192.168.0.25:7860
```

서비스에는 로그인과 공통 비밀번호가 없다. 학생은 화면의 이름 칸에 수업용 별칭을 직접 입력한다. 같은 별칭은 같은 평가표를 공유하므로 `학생A`처럼 겹치지 않는 별칭을 정한다.

## 3. 학생이 평가하는 순서

1. 브라우저에서 교사가 알려 준 주소를 연다.
2. 이름 칸에 별칭을 입력하고 `내 평가표 불러오기`를 누른다.
3. 음식 30개에 1점(매우 싫음)부터 5점(매우 좋음)까지 입력한다.
4. `30개 평점 저장`을 누른다. 중간 저장도 가능하다.
5. 30개를 모두 저장한 뒤 점심 날짜를 골라 `오늘 점심 예상하기`를 누른다.
6. 식사 전 예상 점수를 활동지에 기록한다.
7. 식사 뒤 실제 만족도를 입력하고 `예측과 비교하기`를 누른다.

새로 고침하거나 브라우저를 닫아도 같은 별칭으로 다시 불러오면 저장된 평점이 복원된다. 음식 이름·구분·순서는 바꾸지 않고 평점 열만 수정한다.

## 4. 예측은 어떻게 계산되는가

각 학생의 30개 평점과 오늘 메뉴 이름을 비교한다. 음식 이름은 `돈까`, `까스`처럼 겹치는 문자 조각으로 나누고, 흔한 조각보다 드문 조각에 더 큰 비중을 주는 TF-IDF 벡터로 만든다. 메뉴와 평가 음식의 코사인 유사도가 높고 평점도 높으면 그 메뉴의 예상 선호도가 올라간다.

표에는 메뉴별 예상 선호도와 결과에 영향을 준 평가 음식이 함께 나온다. 이 값은 메뉴 이름의 문자 유사도와 저장한 평점에서 계산한 실험용 추정치다. 영양, 알레르기, 건강, 실제 구매 의사를 판정하지 않는다.

## 5. 저장 위치와 관리

기본 저장 파일은 다음 위치에 생긴다.

```text
runtime_data\student_profiles.sqlite3
```

이 파일은 Git에 포함하지 않는다. 수업이 끝난 뒤 보관이 필요하면 서비스를 `Ctrl+C`로 종료한 뒤 파일을 날짜가 붙은 이름으로 복사한다. 새 실험을 시작할 때는 기존 DB를 바로 지우지 말고 백업한 뒤 교사의 보관 기준에 따라 정리한다.

별칭과 음식 평점 외의 개인정보는 받지 않는다. 학번, 반, 연락처, 질병명, 실제 알레르기 정보는 입력하지 않는다.

## 6. 접속이 안 될 때

- 학생 PC에서 연결되지 않으면 학생과 교사 PC가 같은 네트워크인지, 주소가 교사 PC의 현재 IPv4인지 확인한다.
- 교사 PC에서는 되지만 학생 PC에서는 안 되면 Windows 방화벽의 Python 사설 네트워크 허용을 확인한다.
- `.venv\Scripts\python.exe`를 찾지 못하면 PowerShell의 현재 폴더가 `mnu_summerschool`인지 `Get-Location`으로 확인한다.
- 포트가 이미 사용 중이면 `mokpo_service.py --lan --port 7861`로 실행하고, 안내 주소 끝도 `:7861`로 바꾼다.
- 다른 학생의 평점이 보이면 같은 별칭을 사용한 경우다. 교사가 새 별칭을 정해 다시 불러온다.
