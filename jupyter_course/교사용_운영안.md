# 교사용 수업 운영안

## 수업에서 이루고 싶은 것

학생은 남악고등학교의 NEIS 급식 데이터를 직접 살펴보고, 메뉴 글자를 숫자로 바꾸어 가상 취향과 비교합니다. 5회차가 끝날 때 Jupyter 안에서 추천 화면이 작동해야 하며, 6회차에는 코드를 더 고치지 않고 결과와 한계를 설명합니다.

수업은 여섯 명이 각자 PC에서 같은 장을 실행하는 방식으로 진행합니다. 특정 학생에게 코딩을 맡기기보다 매 활동에서 모든 학생이 값 하나를 직접 바꾸고 자신의 결과를 남기게 합니다.

## 수업 전에 확인할 것

- Python 3.11 이상이 설치되어 있는지 확인합니다.
- 학생이 `00_설치_준비.md`를 보며 `.venv`와 패키지를 직접 준비할 수 있게 프로젝트 폴더를 배포합니다.
- 프로젝트는 짧은 경로에 두고, 설치 뒤에는 같은 작업 폴더를 계속 사용합니다.
- `.\.venv\Scripts\python.exe -m notebook`으로 브라우저가 열리는지 확인합니다.
- 00장을 새 커널에서 실행해 Python, Notebook, 주요 패키지 버전과 예비 급식 5행이 표시되는지 봅니다.
- 06장을 실행해 입력 위젯과 추천 결과 3행이 나타나는지 봅니다.
- 백업할 때는 `.venv` 폴더를 제외하고 학생이 고친 `.ipynb` 파일만 복사합니다.
- 실제 학생의 의료 정보나 알레르기 기록을 입력하지 않는다는 약속을 첫 시간에 안내합니다.
