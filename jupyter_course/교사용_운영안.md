# Jupyter 교과서판 교사용 운영안

## 수업 목표

학생이 공식 NEIS 급식 데이터를 읽고, 문자열 전처리·TF-IDF·코사인 유사도·K-Means·명시적 추천 규칙을 단계적으로 이해한 뒤, Jupyter 안에서 작동하는 개인 취향 추천 프로토타입을 완성하고 한계를 설명한다.

제작은 1~5회차에 끝낸다. 6회차에는 기능을 추가하지 않고 발표·체험·회고만 진행한다.

## 수업 전 준비

- 학생 PC에 Python 3.11 이상이 설치되어 있는지 확인한다.
- 학생이 `00_설치_준비.md`를 보며 `.venv`를 만들고 requirements 설치 명령을 한 줄씩 실행하게 한다.
- `.\.venv\Scripts\python.exe -m notebook`으로 브라우저가 열리는지 확인한다.
- 00장을 새 커널에서 전체 실행해 Python·Notebook·핵심 패키지 버전과 예비 데이터 5행이 표시되는지 확인한다.
- 06장에서 입력 위젯과 추천표 3행이 나타나는지 확인한다.
- 프로젝트를 학생 작업 위치에 처음 한 번만 복사한 뒤 그 위치에서 `.venv`를 만들고, 이후 회차에도 같은 폴더를 사용하게 한다.
- 백업할 때는 옮길 수 없는 `.venv`를 제외하고 수정한 `.ipynb` 파일과 프로젝트 자료만 복사한다.
- 실제 개인 의료 정보를 입력하지 않는 원칙을 먼저 안내한다.
