## 자동으로 확인하는 내용

- 프로젝트 폴더와 `.venv` Python 경로
- 남악고등학교 예비 급식 5행의 구조
- 부록 A의 값·목록·사전·중첩·JSON 변환·실제 예비 파일 6단계
- 목록의 두 번째 메뉴와 실제 예비 JSON 5행
- NEIS GET 요청의 주소·조건·응답 계약과 인증키 비노출
- 실시간 NEIS 조회 실패 시 같은 기간의 예비 자료 사용
- 10개 파일명, 셀 ID, Jupyter 메타데이터
- n-gram 경계 조각과 흔한·드문 조각의 IDF 차이
- 한국어 원문 3편의 SHA-256, 문서별 분석 단어 수와 상위 TF-IDF 상세 계산
- 같은 단어의 문서별 점수 12행과 급식 메뉴 유사도 순위 5행
- 군집과 추천 결과의 필수 값
- 06장 버튼 콜백과 잘못된 입력 안내
- 실행 결과가 모든 코드 셀에 저장되었는지, 02장 그래프가 PNG로 저장되었는지 여부
- 웹 추천기가 남악고 실제 수집본을 우선 사용하고 오류 시 예비 자료로 전환하는지 여부
- 교사용 키 파일의 형식 검증, 프로세스 내 사용, 오류가 나도 환경 변수 복원
- 수집 실패 안내와 공개 JSON에 인증키가 포함되지 않는지 여부
- 공개 급식 필드만 저장하고 남악고·전남교육청·중식 데이터인지 확인하는지 여부
- 목포시 중·고교 31개교와 실제 중식 674행의 출처·날짜·학교 코드·공개 필드 무결성
- 목포대 7월 30·31일 메뉴 원문과 NEIS 자료가 아니라는 출처 표시
- 식사 전 콘텐츠 예측, 실제값을 가린 유저 기반 예측, 혼합 예측과 MAE 비교
- 익명 참여자 6명 제한, 중복 리뷰 거절, CSV 왕복, 식성 군집과 밥친구
- 학교별 빈도·TF-IDF 시그니처, 고등학교 취향 탐색, Pareto·메뉴 조합 대체지표
- 임베딩 사용 불가 시 TF-IDF 전환과 로컬 전용 서비스 설정
- 07장의 네 가지 시험과 모델 카드
- 노트북을 다시 생성해도 같은 파일이 만들어지는지 여부
