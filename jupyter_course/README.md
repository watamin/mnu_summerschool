# 우리 학교 급식 AI — Jupyter 교과서판

이 폴더는 중학교 2학년 학생이 설명을 읽고 코드를 조금씩 바꾸며 개인 취향 기반 급식 추천기를 완성하는 로컬 Jupyter 수업판입니다. 기존 단일 Colab 파일과 달리 내용을 9개 장으로 나누었습니다.

## 가장 먼저 할 일

학교 PC마다 처음 한 번만 작업 폴더를 정한 뒤 진행합니다. `.venv`는 만든 위치를 기억하므로, 설치 뒤 폴더 전체를 다른 곳으로 옮기지 않습니다.

1. Jupyter를 열기 전에 `00_설치_준비.md`를 먼저 읽습니다.
2. 프로젝트 폴더에서 PowerShell을 엽니다.
3. Python 확인 → `.venv` 생성 → pip 갱신 → requirements 설치 명령을 한 줄씩 실행합니다.
4. `.\.venv\Scripts\python.exe -m notebook`을 실행합니다.
5. 브라우저에서 `jupyter_course → chapters → 00_시작하기.ipynb`을 선택합니다.

인터넷 속도에 따라 첫 requirements 설치에는 몇 분이 걸릴 수 있습니다. 이후 수업부터는 가상환경을 다시 만들거나 패키지를 다시 설치하지 않고 Jupyter 실행 명령만 사용합니다.

## 매 수업 시작

1. 처음 설치한 같은 작업 폴더를 계속 사용합니다.
2. 프로젝트 폴더에서 PowerShell을 열고 `.\.venv\Scripts\python.exe -m notebook`을 실행합니다.
3. 오늘 배울 장을 엽니다.
4. 메뉴에서 `Kernel → Restart Kernel and Run All Cells`을 선택합니다.
5. 오류가 없으면 `탐구 활동` 셀의 기본값을 한 곳만 바꿉니다.
6. `Ctrl+S`로 저장합니다.

## 한 장을 공부하는 순서

각 장은 다음 순서로 읽고 실습합니다.

- **이 장에서 배울 내용**에서 학습 목표를 먼저 확인합니다.
- **생각 열기**에서 급식과 학교생활 속 문제를 살펴봅니다.
- **핵심 용어**와 **개념 익히기**를 읽고 새 개념을 정리합니다.
- **활동 전 생각**과 **예상하기**에 자기 생각을 먼저 적습니다.
- 번호가 붙은 **활동**을 순서대로 실행하고 결과를 해석합니다.
- **탐구 활동**에서는 한 번에 한 값만 바꾸어 차이를 기록합니다.
- **확인 문제**를 풀고 **정답과 해설**로 점검한 뒤 **핵심 정리**로 마무리합니다.

코드 전체를 외울 필요는 없습니다. 입력 하나를 바꾸었을 때 출력이 왜 달라졌는지 설명하는 것이 중요합니다.

## 저장과 복구

- 파일명 뒤에 날짜를 붙여 사본을 남깁니다. 예: `05_개인추천_점수설계_0727.ipynb`
- 원본 장 파일은 그대로 두고, 실습 사본을 수정하는 편이 안전합니다.
- 백업할 때 `.venv` 폴더는 제외하고 수정한 `.ipynb` 파일과 프로젝트 자료만 복사합니다.
- 셀 순서가 꼬이면 `Kernel → Restart Kernel and Run All Cells`을 사용합니다.
- 코드를 많이 지웠다면 원본 장의 같은 셀을 복사합니다.
- 화면이 멈추면 브라우저 탭을 닫기 전에 저장부터 시도합니다.

## 자주 생기는 문제

| 화면 또는 증상 | 해결 |
|---|---|
| Python을 찾을 수 없다는 문구 | `00_설치_준비.md` 2단계를 확인하고 교사에게 알림 |
| Jupyter를 시작하지 못함 | `.\.venv\Scripts\python.exe -m pip show notebook` 확인 후 requirements 재설치 |
| 프로젝트 폴더를 찾지 못함 | `neis-meal-ai` 폴더에서 Jupyter 실행 명령을 다시 사용 |
| ModuleNotFoundError | Kernel을 다시 시작하고 처음 셀부터 실행 |
| 그래프가 안 보임 | 해당 장의 위 셀을 먼저 실행 |
| NEIS 서버 오류 | 기본 예비 데이터로 계속 학습 |
| 위젯이 안 보임 | 06장을 저장한 뒤 Kernel 재시작 및 전체 실행 |

## 개인정보와 안전

- 이름, 학번, 반, 연락처, 체중, 질병명은 입력하지 않습니다.
- 실제 개인과 연결되는 알레르기 기록을 입력하지 않습니다.
- 알레르기 선택은 가상 번호로 제외 규칙만 시험합니다.
- 추천 결과는 취향 표현 비교용입니다.
- 실제 식단과 알레르기 정보는 학교 급식표와 영양사 안내를 다시 확인합니다.
