# Jupyter로 만드는 우리 학교 급식 추천기

이 폴더에는 수업에서 사용할 아홉 개의 노트북이 들어 있습니다. 설명을 읽고 코드를 실행한 뒤, 표시된 값을 조금씩 바꾸면서 개인 취향 추천기를 완성합니다. 코드를 모두 외우기보다 “무엇을 바꿨더니 결과가 왜 달라졌는가”를 말할 수 있으면 됩니다.

## 첫 수업 전에

처음 한 번만 작업 폴더를 정합니다. 가상환경은 만든 폴더의 위치를 기억하므로 설치가 끝난 뒤 프로젝트 전체를 다른 곳으로 옮기지 않습니다.

1. `00_설치_준비.md`를 엽니다.
2. 안내에 따라 Python 버전을 확인하고 `.venv`를 만듭니다.
3. `requirements-jupyter.txt`에 적힌 패키지를 설치합니다.
4. 다음 명령으로 Jupyter를 엽니다.

```powershell
.\.venv\Scripts\python.exe -m notebook
```

5. 브라우저에서 `jupyter_course` → `chapters` → `00_시작하기.ipynb`로 들어갑니다.

패키지 설치는 인터넷 속도에 따라 몇 분이 걸릴 수 있습니다. 한 번 설치한 뒤에는 같은 작업 폴더를 계속 사용하고, 다음 수업부터는 Jupyter 실행 명령만 입력합니다.

## 매 수업에서 할 일

1. 프로젝트 폴더에서 PowerShell을 엽니다.
2. 다음 명령으로 Jupyter를 엽니다: `.\.venv\Scripts\python.exe -m notebook`
3. 그날 공부할 장을 엽니다.
4. `Kernel → Restart Kernel and Run All Cells`을 눌러 위에서부터 실행합니다.
5. 결과를 확인한 뒤 `탐구 활동`에 표시된 값 하나만 바꿉니다.
6. 바뀐 결과와 그 까닭을 노트북에 적습니다.
7. `Ctrl+S`로 저장합니다.

## 노트북 순서

| 장 | 파일 | 이번 장에서 다룰 질문 |
|---:|---|---|
| 00 | `00_시작하기.ipynb` | 가상환경과 Jupyter는 왜 필요할까? |
| 01 | `01_NEIS_API와_JSON.ipynb` | JSON 안쪽의 메뉴를 찾고 NEIS에 요청을 보내려면? |
| 02 | `02_급식데이터_정리와_그래프.ipynb` | 복잡한 메뉴 문자열을 어떻게 표로 바꿀까? |
| 03 | `03_TFIDF_글자를_숫자로.ipynb` | n-gram과 TF-IDF로 실제 한국어 문서의 특징어를 어떻게 찾을까? |
| 04 | `04_유사도와_식단군집.ipynb` | 비슷한 메뉴와 비슷한 식단은 어떻게 찾을까? |
| 05 | `05_개인추천_점수설계.ipynb` | 취향이 다르면 추천 순위는 어떻게 달라질까? |

| 08 | `08_발표와_체험.ipynb` | 결과와 한계를 짧고 분명하게 어떻게 설명할까? |

## 노트북 읽는 법

각 장은 하나의 질문으로 시작합니다. 먼저 새로운 용어와 예를 읽고, 코드를 실행하기 전에 어떤 결과가 나올지 생각해 봅니다. 활동 셀은 위에서부터 차례대로 실행합니다.

01장에서는 `{ }`와 `[ ]`를 눈으로 구분하는 데서 시작해 중첩된 NEIS 응답의 메뉴까지 한 칸씩 찾아갑니다. 실제 요청 활동은 기본값이 `False`이므로 먼저 전송될 주소와 학교 코드를 확인한 뒤 `True`로 바꿉니다. 03장에서는 공백 경계를 `·`로 표시해 n-gram을 직접 만들고, TF·DF·IDF를 따로 계산한 뒤 마지막에 곱합니다. 이어서 저장소에 내려받아 둔 한국어 문서 세 편을 읽고 신경망·컴퓨터 비전·책임 있는 AI의 특징어가 어떻게 달라지는지 확인합니다. 문서 원문과 출처는 `data/tfidf_korean_documents`에 있습니다.

`탐구 활동`에서는 여러 곳을 한꺼번에 고치지 않습니다. 값 하나만 바꿔야 어떤 변화가 결과에 영향을 주었는지 찾기 쉽습니다. 마지막 확인 문제는 정답을 외우기 위한 것이 아니라, 화면에서 본 결과를 자기 말로 설명하기 위한 것입니다.

## 저장과 백업

- 원본 노트북은 남겨 두고 파일명 뒤에 날짜를 붙인 사본에서 실습해도 좋습니다. 예: `05_개인추천_점수설계_0728.ipynb`
- 백업할 때는 수정한 `.ipynb` 파일과 활동지만 복사하고 `.venv` 폴더는 제외합니다.
- 셀 실행 순서가 꼬였으면 `Kernel → Restart Kernel and Run All Cells`을 사용합니다.
- 코드를 많이 지웠다면 원본 노트북의 같은 셀을 복사합니다.
- 화면이 멈춘 것처럼 보여도 브라우저를 닫기 전에 먼저 저장합니다.

## 문제가 생겼을 때

| 화면에 보이는 문제 | 먼저 해 볼 일 |
|---|---|
| Python을 찾을 수 없음 | `00_설치_준비.md`의 Python 확인 단계로 돌아가기 |
| Jupyter가 시작되지 않음 | `.\.venv\Scripts\python.exe -m pip show notebook` 실행하기 |
| 프로젝트 폴더를 찾지 못함 | 프로젝트 최상위 폴더에서 Jupyter를 다시 열기 |
| `ModuleNotFoundError` | 커널을 다시 시작하고 첫 셀부터 실행하기 |
| 그래프가 보이지 않음 | 같은 장의 위쪽 코드 셀이 실행되었는지 확인하기 |
| NEIS 조회 오류 | 화면에 표시된 예비 데이터로 수업 계속하기 |
| 입력 위젯이 보이지 않음 | 06장을 저장하고 커널을 다시 시작한 뒤 전체 실행하기 |

## 꼭 지킬 약속

- 이름, 학번, 반, 연락처, 체중, 질병명은 입력하지 않습니다.
- 실제 개인과 연결되는 알레르기 기록도 입력하지 않습니다.
- 알레르기 번호는 제외 규칙을 살펴보는 가상 값으로만 사용합니다.
- 추천 점수와 식단 묶음은 건강 판정이 아닙니다.
- 실제 메뉴와 알레르기 정보는 학교 급식표와 영양사 안내를 다시 확인합니다.
