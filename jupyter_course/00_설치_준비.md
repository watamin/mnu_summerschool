# 수업을 위한 Python과 Jupyter 준비

설치 전에는 Jupyter Notebook을 열 수 없습니다. 이 문서를 화면에 띄워 두고 PowerShell 명령을 위에서부터 한 줄씩 실행하세요. 설치가 끝나면 `chapters/00_시작하기.ipynb`를 엽니다.

## 가상환경은 왜 만들까요?

가상환경은 이 프로젝트만 쓰는 작은 Python 작업 상자입니다.

```text
학교 PC의 Python
└─ .venv
   ├─ Python
   ├─ Jupyter Notebook
   ├─ Pandas·NumPy
   ├─ Matplotlib
   └─ ipywidgets
```

필요한 도구를 `.venv` 안에 모아 두면 다른 수업에서 설치한 패키지와 섞이지 않습니다. 문제가 생겼을 때 어느 환경을 확인해야 하는지도 분명해집니다.

## 1. 프로젝트 폴더에서 PowerShell 열기

파일 탐색기에서 `mnu_summerschool` 폴더를 엽니다. 주소 표시줄에 `powershell`을 입력하고 Enter를 누릅니다.

```powershell
Get-Location
Get-ChildItem
```

파일 목록에 `requirements-jupyter.txt`, `jupyter_course`, `src`가 보이면 알맞은 폴더에 들어온 것입니다.

## 2. Python 버전 확인하기

```powershell
py -3 --version
```

`Python 3.11` 이상이 표시되면 다음 단계로 갑니다. 명령을 찾을 수 없거나 버전이 3.10 이하라면 다른 프로그램을 임의로 설치하지 말고 교사에게 알립니다.

## 3. 가상환경 만들기

```powershell
py -3 -m venv .venv
```

이 명령은 현재 폴더에 `.venv`라는 가상환경을 만듭니다. 프로젝트를 처음 준비할 때 한 번만 실행합니다. 완료된 뒤 다음 명령으로 숨김 폴더까지 확인할 수 있습니다.

```powershell
Get-ChildItem -Force
```

이 수업에서는 PowerShell 실행 정책 문제를 피하기 위해 활성화 명령을 사용하지 않습니다. 대신 아래 단계처럼 `.venv` 안의 Python 경로를 직접 적습니다.

## 4. pip 갱신하기

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
```

`pip`는 Python 패키지를 설치하는 도구입니다. 명령 앞에 `.venv\Scripts\python.exe`가 있으므로 학교 PC 전체가 아니라 방금 만든 가상환경의 pip만 바뀝니다.

## 5. 수업 패키지 설치하기

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-jupyter.txt
```

`requirements-jupyter.txt`에는 설치할 패키지가 한 줄에 하나씩 적혀 있습니다. `>=`는 사용할 수 있는 가장 낮은 버전, `<`는 넘어가지 않을 큰 버전을 뜻합니다.

| 패키지 | 이 수업에서 하는 일 |
|---|---|
| notebook | 브라우저에서 Jupyter 화면 열기 |
| ipykernel | 코드 셀의 Python 실행하기 |
| ipywidgets | 06장의 입력 상자와 버튼 만들기 |
| pandas·numpy | 급식표와 숫자 다루기 |
| matplotlib | 02장의 막대그래프 그리기 |
| requests | NEIS 서버에 데이터 요청하기 |
| nbformat·nbclient | 노트북 파일과 새 커널 실행 확인하기 |

다운로드가 끝날 때까지 PowerShell 창을 닫지 않습니다.

## 6. 설치 결과 확인하기

```powershell
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m pip show notebook
```

`pip check`에서 `No broken requirements found.`가 보이면 패키지 연결에 문제가 없는 것입니다. `pip show notebook`에서는 Notebook의 버전과 설치 위치를 확인할 수 있습니다.

## 7. Jupyter Notebook 열기

```powershell
.\.venv\Scripts\python.exe -m notebook
```

잠시 뒤 브라우저가 열립니다. `jupyter_course` → `chapters` → `00_시작하기.ipynb` 순서로 들어갑니다. Jupyter를 사용하는 동안 PowerShell 창은 닫지 않습니다.

## 수업을 마칠 때

1. 노트북에서 `File → Save Notebook`을 눌러 저장합니다.
2. PowerShell 창을 선택합니다.
3. `Ctrl+C`를 누릅니다.
4. 종료 질문이 나오면 `y`를 입력합니다.

다음 수업부터 가상환경을 다시 만들거나 패키지를 다시 설치하지 않습니다. 같은 작업 폴더를 계속 사용하고 7번의 Jupyter 실행 명령만 입력합니다. 백업할 때는 `.venv` 폴더를 제외하고 수정한 노트북과 활동지만 복사합니다.

## 설치가 멈췄을 때

| 화면에 보이는 문제 | 확인할 것 | 다음 행동 |
|---|---|---|
| `py` 명령을 찾을 수 없음 | Python 설치 여부 | 교사에게 알리고 Python 3.11 이상인지 확인 |
| `.venv` 경로를 찾을 수 없음 | 현재 폴더의 `requirements-jupyter.txt` | 1번으로 돌아가 폴더 다시 확인 |
| 패키지 다운로드 실패 | 인터넷 연결 | 연결을 확인하고 5번 명령 다시 실행 |
| `Long Path` 오류 | 프로젝트 폴더의 전체 경로 | `C:\AI\mnu_summerschool`처럼 짧은 위치로 옮긴 뒤 `.venv` 다시 만들기 |
| Notebook 모듈이 없음 | `pip show notebook` 결과 | 5번 명령 다시 실행 |
| 브라우저가 자동으로 열리지 않음 | PowerShell의 `http://localhost:...` 주소 | 주소를 복사해 브라우저에 직접 입력 |

설치 과정에서도 비밀번호, 이름, 학번, 질병명, 실제 개인과 연결되는 알레르기 정보를 입력하지 않습니다.
