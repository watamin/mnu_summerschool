# 00장 준비 — 가상환경과 Jupyter를 한 단계씩 설치하기

이 문서는 **설치 전에는 Jupyter Notebook을 열 수 없습니다**라는 문제를 해결하는 첫 페이지입니다. 먼저 이 문서를 보면서 PowerShell 명령을 한 줄씩 실행하고, 설치가 끝난 뒤 `chapters/00_시작하기.ipynb`를 엽니다.

## 우리가 만드는 설치 구조

```text
학교 PC의 Python
└─ .venv                ← 이 프로젝트만 쓰는 가상환경
   ├─ Python
   ├─ Jupyter Notebook
   ├─ Pandas·NumPy
   └─ Matplotlib·ipywidgets
```

가상환경은 프로젝트마다 따로 쓰는 공구함입니다. 다른 수업의 Python 패키지와 섞이지 않아 고장 원인을 찾기 쉽습니다.

## 1단계 — 프로젝트 폴더에서 PowerShell 열기

파일 탐색기에서 `neis-meal-ai` 폴더를 엽니다. 주소 표시줄에 `powershell`을 입력하고 Enter를 누릅니다. 아래 명령으로 현재 폴더를 확인합니다.

```powershell
Get-Location
Get-ChildItem
```

목록에 `requirements-jupyter.txt`, `jupyter_course`, `src`가 보여야 합니다.

## 2단계 — Python 버전 확인하기

```powershell
py -3 --version
```

`Python 3.11` 이상이면 계속합니다. 명령을 찾을 수 없거나 3.10 이하라면 혼자 다른 프로그램을 설치하지 말고 교사에게 알립니다.

## 3단계 — 가상환경 만들기

```powershell
py -3 -m venv .venv
```

- `-m venv`는 가상환경을 만드는 Python 도구입니다.
- `.venv`는 새 공구함 폴더의 이름입니다.
- 명령이 끝난 뒤 `Get-ChildItem -Force`를 실행하면 `.venv`가 보입니다.

수업에서는 PowerShell 실행 정책 문제를 줄이기 위해 활성화 명령 대신 가상환경 Python의 전체 경로를 직접 사용합니다.

## 4단계 — 가상환경의 pip 갱신하기

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
```

`pip`는 Python 패키지를 설치하는 도구입니다. 앞에 `.venv\Scripts\python.exe`를 붙였으므로 학교 PC 전체가 아니라 이번 프로젝트의 가상환경만 바뀝니다.

## 5단계 — requirements 패키지 설치하기

먼저 `requirements-jupyter.txt`를 메모장으로 열어 보세요. 한 줄이 패키지 하나이며, `>=`는 최소 버전, `<`는 넘어가면 안 되는 큰 버전을 뜻합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-jupyter.txt
```

설치되는 핵심 도구는 다음과 같습니다.

| 패키지 | 이 프로젝트에서 하는 일 |
|---|---|
| notebook | 브라우저에서 전자 교과서를 실행 |
| ipykernel | Code 셀의 Python 코드를 계산 |
| ipywidgets | 06장의 입력 상자와 추천 버튼 |
| pandas·numpy | 급식 표와 숫자 계산 |
| matplotlib | 02장의 막대그래프 |
| requests | 공식 NEIS API 요청 |
| nbformat·nbclient | 교사가 9개 장을 자동 검증 |

## 6단계 — 설치 확인하기

```powershell
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m pip show notebook
```

`pip check`가 `No broken requirements found.`를 보여 주면 패키지 연결이 정상입니다. `pip show notebook`에는 설치된 Notebook 버전과 위치가 나타납니다.

## 7단계 — Jupyter Notebook 실행하기

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m notebook
```

브라우저가 열리면 `jupyter_course` → `chapters` → `00_시작하기.ipynb` 순서로 들어갑니다. PowerShell 창은 Jupyter가 실행되는 동안 닫지 않습니다.

## 8단계 — 수업을 마칠 때 종료하기

1. 노트북에서 `File → Save Notebook`으로 저장합니다.
2. PowerShell 창을 선택합니다.
3. `Ctrl+C`를 누르고 종료 질문이 나오면 `y`를 입력합니다.

다음 수업부터는 가상환경을 다시 만들거나 패키지를 다시 설치하지 않습니다. 처음 `.venv`를 만든 같은 작업 폴더를 계속 사용하고, 그 폴더에서 7단계 실행 명령만 사용합니다. 백업할 때는 `.venv` 폴더를 제외하고 수정한 `.ipynb` 파일과 프로젝트 자료만 복사합니다.

## 오류가 났을 때

| 화면의 상황 | 먼저 확인할 것 | 다음 행동 |
|---|---|---|
| `py`를 찾을 수 없음 | Python 설치 여부 | 교사에게 알리고 Python 3.11 이상 확인 |
| `.venv` 경로를 찾을 수 없음 | 현재 폴더의 `requirements-jupyter.txt` | 1단계부터 현재 폴더 확인 |
| 패키지 다운로드 실패 | 인터넷 연결 | 연결 확인 후 5단계 명령 재실행 |
| `Long Path` 또는 경로가 너무 길다는 오류 | 프로젝트 폴더의 전체 경로 | 프로젝트를 `C:\AI\neis-meal-ai`처럼 짧은 위치로 옮기고 3단계부터 재실행 |
| Notebook 모듈이 없음 | `pip show notebook` 결과 | 5단계 requirements 설치 재실행 |
| 브라우저가 자동으로 안 열림 | PowerShell의 `http://localhost:...` 주소 | 그 주소를 브라우저에 직접 입력 |

비밀번호, 이름, 학번, 실제 질병명이나 실제 개인과 연결된 알레르기 기록은 설치 과정과 노트북 어디에도 입력하지 않습니다.
