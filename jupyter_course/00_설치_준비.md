# 수업을 위한 Python과 Jupyter 준비

설치 명령은 Jupyter의 코드 칸이 아니라 프로젝트 폴더에서 연 **PowerShell**에 한 줄씩 입력합니다. 설치 전에는 Jupyter Notebook을 열 수 없습니다. 한 단계가 끝난 것을 확인한 뒤 다음 단계로 갑니다.

## 가상환경은 왜 만들까요?

가상환경은 이 프로젝트만 쓰는 작은 공구함입니다. `.venv` 안에 Jupyter, 데이터 처리 도구, 웹 화면 도구를 모아 두면 다른 수업에서 설치한 패키지와 섞이지 않습니다.

```text
학교 PC의 Python
└─ 이 프로젝트의 .venv
   ├─ Jupyter Notebook
   ├─ Pandas·NumPy
   ├─ Matplotlib
   ├─ ipywidgets
   └─ Gradio 웹 화면
```

## 1. 프로젝트 폴더에서 PowerShell 열기

파일 탐색기에서 `mnu_summerschool` 폴더를 엽니다. 주소 표시줄에 `powershell`을 입력하고 Enter를 누른 뒤 다음 명령으로 위치와 파일을 확인합니다.

```powershell
Get-Location
Get-ChildItem
```

목록에 `requirements-jupyter.txt`, `jupyter_course`, `src`, `web_app.py`가 보이면 맞는 폴더입니다.

## 2. Python 버전 확인하기

```powershell
py -3 --version
```

`Python 3.11` 이상이면 다음 단계로 갑니다. 명령을 찾을 수 없거나 버전이 3.10 이하라면 임의로 설치하지 말고 교사에게 알립니다.

## 3. 가상환경 만들기

```powershell
py -3 -m venv .venv
```

프로젝트 폴더에 `.venv`가 생깁니다. 처음 준비할 때 한 번만 실행합니다. 이 수업에서는 PowerShell 실행 정책에 영향을 받지 않도록 활성화 명령 대신 `.venv` 안의 Python 경로를 직접 사용합니다.

## 4. pip 갱신하기

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
```

`pip`는 Python 패키지를 내려받고 설치하는 도구입니다. 명령 앞에 `.venv\Scripts\python.exe`가 있으므로 방금 만든 가상환경 안의 pip만 갱신됩니다.

## 5. 수업 패키지 설치하기

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-jupyter.txt
```

`requirements-jupyter.txt`에 적힌 패키지를 차례대로 설치합니다. 다운로드가 끝날 때까지 PowerShell 창을 닫지 않습니다.

| 패키지 | 이 수업에서 하는 일 |
|---|---|
| notebook | 브라우저에서 Jupyter 화면 열기 |
| ipykernel | 코드 칸의 Python 실행하기 |
| ipywidgets | 06장의 입력 상자와 버튼 만들기 |
| gradio | 완성된 추천기를 간단한 웹 화면으로 열기 |
| pandas·numpy | 급식표와 숫자 다루기 |
| matplotlib | 02장의 막대그래프 그리기 |
| requests | NEIS 서버에 데이터 요청하기 |
| nbformat·nbclient | 노트북 파일과 실행 결과 확인하기 |

## 6. 설치 결과 확인하기

```powershell
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m pip show notebook gradio
```

`pip check`에서 `No broken requirements found.`가 보이면 패키지 연결에 문제가 없다는 뜻입니다. 마지막 명령에서는 Notebook과 Gradio의 버전·설치 위치를 확인할 수 있습니다.

## 7. Jupyter Notebook 열기

```powershell
.\.venv\Scripts\python.exe -m notebook
```

브라우저가 열리면 `jupyter_course` → `chapters` → `00_시작하기.ipynb` 순서로 들어갑니다. 노트북에는 실행 결과가 저장되어 있어 코드를 누르지 않아도 표와 그래프를 먼저 읽을 수 있습니다. 직접 실험할 때는 위에서 아래로 실행합니다.

## 8. 완성된 웹 추천기 열기

Jupyter를 종료한 뒤 프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
.\.venv\Scripts\python.exe web_app.py
```

브라우저에 `우리 학교 급식 추천 실험실`이 열립니다. 남악고 NEIS 예비 데이터 5일이 준비되어 있으므로 좋아하는 메뉴와 가상 취향을 정하고 `추천 결과 보기`를 누르면 됩니다. 주소는 이 PC 안에서만 열리는 `127.0.0.1`을 사용합니다.

## 수업을 마칠 때

1. 노트북을 사용했다면 `File → Save Notebook`으로 저장합니다.
2. PowerShell 창을 선택합니다.
3. `Ctrl+C`를 누릅니다.
4. 종료 질문이 나오면 `y`를 입력합니다.

다음 수업부터는 가상환경이나 패키지를 다시 만들지 않고 같은 작업 폴더를 계속 사용합니다. Jupyter 또는 웹 추천기 실행 명령만 다시 입력합니다. 백업할 때는 수정한 노트북과 활동지만 복사하고 `.venv` 폴더는 제외합니다.

## 설치가 멈췄을 때

| 화면에 보이는 문제 | 확인할 것 | 다음 행동 |
|---|---|---|
| `py` 명령을 찾을 수 없음 | Python 설치 여부 | 교사에게 알리고 Python 3.11 이상인지 확인 |
| `.venv` 경로를 찾을 수 없음 | 현재 폴더에 `requirements-jupyter.txt`가 있는지 | 1단계로 돌아가 폴더 다시 확인 |
| 패키지 다운로드 실패 | 인터넷 연결 | 연결을 확인하고 5단계 명령 다시 실행 |
| `Long Path` 오류 | 프로젝트 폴더의 전체 경로 | `C:\AI\mnu_summerschool`처럼 짧은 위치로 옮긴 뒤 `.venv` 다시 만들기 |
| Notebook 모듈이 없음 | `pip show notebook` 결과 | 5단계 명령 다시 실행 |
| 웹 화면이 열리지 않음 | PowerShell에 표시된 `http://127.0.0.1:...` 주소 | 주소를 브라우저에 직접 입력 |

설치 과정과 웹 추천기에는 이름, 학번, 반, 연락처, 체중, 질병명을 입력하지 않습니다. 실제 개인과 연결되는 알레르기 정보도 입력하지 않고 수업용 가상 번호만 사용합니다.
